Acciones por marca

1. Descarga la plantilla

Trae las columnas exactas de cada reporte y una fila de ejemplo. También puedes subir el Excel tal como sale del sistema, siempre que tenga esas columnas.

VentasTodas las marcas, sin Cliente ni Artículo. Venta, unidades y clientes activados.
Tubrica por códigoSolo Tubrica, con Artículo y sin Cliente. Para las toneladas.
Tabla de pesoCódigo, Kg y Ton por unidad de Tubrica.
InfocomprasG03 y G10. Inventario, cobertura y días sin inventario.
Plantilla llenaSube el mismo archivo una vez por cada tipo: el dashboard toma la hoja que corresponde e ignora la fila de EJEMPLO.
ClientesRegión, Estado, Supervisor, Asesor, Marca, Cliente y Mes, con Venta Neta. Sin artículo. Para clientes únicos.
Ventas semanalesHojas Sheet1, Presupuesto, Acciones y Sheet2. Para Presupuesto, KPI semanal y KPI por Región.

2. Carga el archivo

Elige qué reporte es y selecciona el archivo (.xlsx o .csv). Con una plantilla llena, elige «Plantilla mensual completa» o «Plantilla ventas semanales» y súbela una sola vez: se actualizan todas sus hojas con datos. Antes de actualizar se revisan las columnas y si el sistema lo cortó por límite de filas. Un archivo cortado no se aplica.

    3. Archivos cargados

    Al subir, el dashboard se actualiza en el momento y el archivo queda como Aplicado. Si algo falla, queda como Rechazado con el motivo.
